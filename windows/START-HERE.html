IPMsg Phone Dock

0.6.0 preview · Offline · Windows x64

Connect

Exit the old dock using its tray menu, then run Setup or extract the whole portable ZIP. Connect the phone by USB, approve Android debugging and click Connect. For Android 11+ Wi-Fi, use Set up Wi-Fi → Scan QR and Android Wireless debugging pairing.

Choose. Prepare. Drag.

  1. Click Files and approve the temporary session on your phone.
  2. Select files/photos. Previews arrive first; cards show preparation progress.
  3. When a card says Ready to drag, drag it to a Windows folder. This uses ordinary native file drops; no unfinished phone stream is offered.

Enter or right-click → Save to PC is the destination-picker alternative. Clear tray ends sharing and preparation. × only hides the shelf.

Temporary by design

The list clears when sharing ends. Private PC source copies receive a one-hour grace after retirement/last in-flight use so Windows can finish copying. Cleanup runs every five minutes while the dock is running/in the tray, and on the next launch. Full exit/uninstall cannot perform future cleanup. Windows destination files are never deleted.

Keep it compact

280-pixel default width. F11 fullscreen; Esc return; F6 More. Ctrl+Alt+I shows/hides the running dock; personalize it in Window → Shortcuts & startup. Close/minimize pauses the phone and keeps the tray process. Exit quits completely.

Existing Android 0.8.0 APK unchanged. Windows binaries are unsigned previews. Local checks pass; final physical Explorer drag and installer acceptance remain pending.
