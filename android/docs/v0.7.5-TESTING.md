Checks cover bounded audio retention, mute epochs/stream closure, authentication, no remote microphone activation, single audio stream, TLS trust, receiver-only recording access, previous routing and recovery behavior. Open/close Chat while viewing from Windows: the camera surface, HTTPS link and stream must stay active. Send/receive text, copy/quote, delivery failures, offline drafts, and recover a camera draft without overwriting a different main-chat draft.
- With microphone permission missing, denied, previously granted and revoked, every new session must begin muted. Only an owner-confirmed Mic action may enable capture. Test permission-dialog return, screen off, Home/Recents, locking, app/process exit, expiry, device revocation and LAN change. Capture must end; receiver controls must never reactivate it.
- In current Windows Edge and Chrome, opt into Sound, hear phone audio, mute on either side, and verify queued audio clears. Re-enable sound and confirm no old audio replays. Test another recording app and Android microphone privacy controls. Evaluate latency, bandwidth, battery use and sound/video alignment before making performance claims.
- Record a playable receiver-only WebM while sound is off/on and changes during a clip. Verify mute produces silence, photo/recording alerts remain visible on phone, no capture is saved there, and time/approximate 96 MiB limits download correctly. Test tab background/close, expired/revoked session, interruption and unavailable Web Audio/MediaRecorder support.

- Samsung S25 Ultra and OnePlus Ace 5: create a hotspot with mobile data disabled, connect Windows 5.9.1, discover both directions, exchange Unicode and files both ways, and open the HTTPS viewer. Repeat after restarting the hotspot, changing subnet, reconnecting with the same IP, and toggling cellular while a camera session remains on the same LAN.

A plaintext text/file offer must be rejected in strict-message mode; unencrypted Windows file downloads must produce a visible security explanation in strict-file mode. - Review light/dark UI, large text and TalkBack on phone. Confirm existing chats, settings and saved-file links survive the in-place update.
