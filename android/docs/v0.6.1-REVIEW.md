# IPMsg 0.6.1 release-candidate changes

This update addresses the reported conversation naming, bubble clarity, sideways sender preview and camera lag. Physical-phone results remain pending. It preserves four tabs, local operation, the same application ID/signing lineage and Windows IPMsg compatibility.

## Findings and changes

The conversation list used a peer's raw name while the header used a nickname only for online peers. Both now resolve through the same naming policy. Known names refresh on discovery without granting approval, and local nicknames remain visible offline. Chat titles open a small nickname editor.

Each message now has a clearly outlined incoming or outgoing bubble with neutral/green colors, readable contrast and directional corners. Redundant offline queue controls and unnecessary older-page buttons were removed.

The camera previously rotated a SurfaceTexture preview by the sensor orientation a second time. It now uses the standard display transform and aspect fit. Raw YUV browser frames use explicit, stride-aware quarter-turn rotation. A single background encoder reads the latest camera image, reuses its conversion buffer and drops excess work. The browser receives a continuous authenticated HTTPS multipart JPEG stream, avoiding a fresh TLS connection for every frame. Slow writes are bounded and frames are not queued. Owner recording permission and immediate session shutdown remain intact.

## Practical limits

No physical Galaxy S25 Ultra or OnePlus Ace 5 is connected. Correct physical orientation and latency on those phones still need user confirmation. Emulator frame/recording tests do not establish Wi-Fi performance or battery use. The target of ten encoded frames per second is a cap, not a measured guarantee. Unsupported recording stream combinations use a smaller compatibility preview near three frames/second. Slow startup does not switch the normal stream to UI readback. Classic IPMsg file bodies remain unauthenticated; interrupted downloads restart from zero. Physical acceptance from the 0.6 plan remains pending.
