Repeat after restarting the hotspot, changing subnet, reconnecting with the same IP, and toggling cellular while a camera session remains on the same LAN.
- Check Windows Firewall for the hotspot's actual network profile; allow UDP/TCP 2425 only on the trusted local network. Verify a stale saved IP does not block discovery.
- Test both security switches independently. A plaintext text/file offer must be rejected in strict-message mode; unencrypted Windows file downloads must produce a visible security explanation in strict-file mode. Encrypted requests must remain encrypted. Confirm incoming file-body plaintext still needs explicit acceptance and secure identities never silently downgrade.
- Flashlight on/off on supported hardware, unavailable hardware, leave screen, lock screen, Stop, network change and camera failure. Confirm light goes off, preview continues, and receiver cannot operate it.
- Review light/dark UI, large text and TalkBack on phone. Confirm existing chats, settings and saved-file links survive the in-place update.

No throughput, battery or physical interoperability improvement is claimed by this release candidate. Existing Windows/browser and screen-off acceptance items remain pending.
