# Security policy

Use the current release and keep Android USB/Wireless debugging limited to your own trusted PC. ADB authorization grants broad device access.

Do not publish credentials, private signing material, phone identifiers, or exploit details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise, contact the maintainer through GitHub before public disclosure.

This project has not had an independent penetration test. See the component security reviews for known limitations.
